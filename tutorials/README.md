# neural Tutorial Patches

Load these from the app with `Load`:

- `tutorial_01_basic_synth.json`: dual oscillator -> mix -> filter -> stereo out
- `tutorial_02_filter_modulation.json`: audio-rate modulation driving filter cutoff
- `tutorial_03_reverb.json`: basic Schroeder-style reverb (comb + allpass network)
- `tutorial_04_sample_hold_pattern.json`: generative sample-and-hold pitch pattern synth
- `tutorial_05_bit_lab.json`: bit-crush/quantize/per-bit-delay chain
- `tutorial_06_advanced_feedback.json`: matrix-routed dual feedback loops with freeze control
- `tutorial_07_advanced_feedback_extreme.json`: rungler-style stepped CV synth (clocked S&H shift chain -> pitch/timbre)
- `tutorial_08_neuron_generative_system.json`: neuron-driven generative system with AD envelope shaping (clocked stepped pitch + waveform/timbre motion)
- `tutorial_09_radigue_drone.json`: slow evolving multi-oscillator drone with long AD swells, drifting phase motion, and spacious diffusion
- `tutorial_10_chiptune_band.json`: evolving chiptune mini-song with clocked arpeggio, bassline, kick, and noise snare/hat arranged as verse, chorus, verse, chorus, bridge, chorus

Notes:
- For feedback-heavy patches, start with lower output volume and raise slowly.
